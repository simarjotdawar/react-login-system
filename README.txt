React Login System - Experiment

1. Extract this folder.
2. Open the folder in VS Code.
3. Open the VS Code terminal.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the localhost URL shown by Vite.

Login credentials:
Admin: admin / admin123
User: user / user123

Concepts covered:
- Authentication
- Simulated JWT/token generation
- Token storage using localStorage
- Token decoding
- Role display
- Protected dashboard
- Logout

This is a frontend educational simulation. A real JWT system should generate and verify tokens on a backend.
